# Dynamic Image Gallery

A modern, fully responsive Image Gallery application built with React.js that demonstrates core React concepts such as reusable components, props, and dynamic rendering using the `map()` method. The project is designed with scalability, clean code practices, and an intuitive user experience in mind.

The gallery dynamically displays image data from an array of objects, making it easy to add, modify, or manage content without changing the JSX structure. It features smooth animations, responsive layouts, and a component-based architecture that follows modern frontend development best practices.

## Features

- Reusable and modular React components
- Dynamic rendering of images using the `map()` method
- Parent-to-child data passing using Props
- Responsive design for Mobile, Tablet, and Desktop devices
- Modern UI with smooth hover animations and transitions
- Clean and scalable component-based architecture
- Easily maintainable image data structure
- Production-ready deployment on Vercel
